The 60-minute rule

Pickup 11:00 → Start required by 10:00.

At the cutoff, an unstarted pickup raises Not started. A different active task does not satisfy this rule. Starting the correct task clears the alert on the next successful check. Start time is not inferred from online status or GPS movement.
